## Структура таблицы Category в БД

```sql
id          SERIAL PRIMARY KEY
parent_id   INT NULL REFERENCES category(id)   -- NULL для групп верхнего уровня
name        VARCHAR(200) NOT NULL
slug        VARCHAR(200) NOT NULL UNIQUE        -- url-friendly название
metadata    JSONB DEFAULT '{}'                  -- атрибуты для AI-подбора
sort_order  INT DEFAULT 0
created_at  TIMESTAMP DEFAULT NOW()
```

Группы (13 шт) — записи с parent_id = NULL.
Категории — записи с parent_id = id группы.
(В MVP используем одноуровневую модель: группы — это просто поле group_name, без вложенных категорий.)
